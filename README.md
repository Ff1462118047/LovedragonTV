# LovedragonTV
队里有梦梓宝贝就变成妈咪粉：岔路口自动追过去，进商店自动给她转账。顺带在命令窗发癫。（i龙TV❤️永存）
<img width="1152" height="1480" alt="a03d0afb4ec0597e1d8837cb540865df" src="https://github.com/user-attachments/assets/806be9fc-53ef-4dd6-a53b-2ddf42a04fe2" />
## 功能
- 岔路自动选离真梦梓最近的路线
- 进商店自动给她转账
- 命令窗发癫日志（i龙TV❤️）

![商店转账](images/shop.png)

## 安装
把 zip 拖进 [AstralParty Toys](https://github.com/higashitaniyume/AstralParty.Toys) 的「导入 Mod」，或解压到 `mods\LovedragonTV\`

## 配置
在 Toys 的 ⚙ 里改：总开关 / 角色名 / 岔路跟随 / 商店转账 / 调试日志
